# Sarvyanta Makeup Artist

One-page makeup artist enquiry and demand-generation website.

## Intended Domain

https://makeupartist.sarvyanta.com/

## Purpose

The website is designed to capture makeup artist demand across Telangana
without restricting the website to Hyderabad or any single locality.

Primary topic:

Makeup Artist

Secondary services:

- Bridal Makeup
- Wedding Makeup
- Engagement Makeup
- Reception Makeup
- Party Makeup
- HD Makeup
- Airbrush Makeup
- Makeup at Home
- Special Occasion Makeup

## WhatsApp

Sarvyanta WhatsApp:

+91 7386406514

The visitor can select:

- No services
- One service
- Multiple services

The WhatsApp button never blocks the visitor.

### No services selected

The message becomes:

Hi Sarvyanta, I am interested in makeup artist services.
Please let me know the available options and details.

### Services selected

The selected service names are automatically inserted into
the WhatsApp message.

Then configure:

After the domain is live, submit:

https://makeupartist.sarvyanta.com/sitemap.xml

to Google Search Console.
